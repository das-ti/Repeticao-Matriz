# Atividade Prática 2 - REPETIÇÃO E MATRIZ

## Instruções
Crie um programa que:

1. Soma de Matrizes:
    - Realiza a soma de duas matrizes 3X3;
    - exibindo o resultado no console. 

2. Multiplicação de Matriz por Escalar:
    - Verifique se um login e senha confere com os dados de uma matriz 6x2.

3. Transposição de Matriz:
    - (as colunas viram linhas e as linhas viram colunas);
    - Peça aos usuários para inserirem os elementos da matriz;
    -  exibindo a matriz transposta no console.
